# 配置指南

本文档说明如何配置项目的各项功能。

## 快速配置

### 1. 创建 `.env` 文件

在项目根目录创建 `.env` 文件（参考 `.env.example`）：

```bash
# 飞书推送配置（必需）
FEISHU_WEBHOOK_URL=https://open.feishu.cn/open-apis/bot/v2/hook/your-webhook-url
# 注意：如果机器人未启用签名校验，不需要设置 FEISHU_WEBHOOK_SECRET

# LLM配置（可选，如需LLM分析）
ALIYUN_BAILIAN_API_KEY=your-api-key
ALIYUN_BAILIAN_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1/chat/completions

# OSS配置（可选，如需OSS上传报告）
OSS_BUCKET_NAME=your-bucket-name
OSS_ENDPOINT=oss-cn-beijing.aliyuncs.com
OSS_ACCESS_KEY_ID=your-access-key-id
OSS_ACCESS_KEY_SECRET=your-access-key-secret
```

## 详细配置说明

### 飞书推送配置

#### 必需配置

- **FEISHU_WEBHOOK_URL**：飞书机器人Webhook URL
  - 获取方式：在飞书群聊中添加自定义机器人，获取Webhook URL
  - 格式：`https://open.feishu.cn/open-apis/bot/v2/hook/xxxxx`

#### 可选配置

- **FEISHU_WEBHOOK_SECRET**：签名密钥（仅在机器人启用签名校验时需要）
  - 如果机器人未启用签名校验，可以不设置此变量

#### 配置方式

**方式1：使用 `.env` 文件（推荐）**

在项目根目录的 `.env` 文件中添加：
```bash
FEISHU_WEBHOOK_URL=https://open.feishu.cn/open-apis/bot/v2/hook/your-webhook-url
```

**方式2：系统环境变量**

Windows PowerShell:
```powershell
$env:FEISHU_WEBHOOK_URL="https://open.feishu.cn/open-apis/bot/v2/hook/your-webhook-url"
```

Windows CMD:
```cmd
set FEISHU_WEBHOOK_URL=https://open.feishu.cn/open-apis/bot/v2/hook/your-webhook-url
```

Linux/Mac:
```bash
export FEISHU_WEBHOOK_URL="https://open.feishu.cn/open-apis/bot/v2/hook/your-webhook-url"
```

### LLM配置

项目支持多种LLM提供商，按优先级自动选择：

1. **阿里云百炼**（优先）
2. **OpenAI**
3. **Dify**

#### 阿里云百炼配置

```bash
ALIYUN_BAILIAN_API_KEY=your-api-key
ALIYUN_BAILIAN_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1/chat/completions
```

- `ALIYUN_BAILIAN_API_KEY`：必需，API密钥
- `ALIYUN_BAILIAN_BASE_URL`：可选，默认使用官方API地址

#### OpenAI配置

```bash
OPENAI_API_KEY=your-api-key
```

#### Dify配置

```bash
DIFY_API_KEY=your-api-key
DIFY_BASE_URL=https://api.dify.ai/v1
```

- `DIFY_API_KEY`：必需
- `DIFY_BASE_URL`：可选，有默认值

### OSS配置

用于上传报告文件到阿里云OSS，生成可访问的URL。

#### 必需配置

```bash
OSS_BUCKET_NAME=your-bucket-name
OSS_ENDPOINT=oss-cn-beijing.aliyuncs.com
OSS_ACCESS_KEY_ID=your-access-key-id
OSS_ACCESS_KEY_SECRET=your-access-key-secret
```

#### 配置说明

- **OSS_BUCKET_NAME**：OSS存储桶名称
- **OSS_ENDPOINT**：OSS服务端点（根据地域选择）
- **OSS_ACCESS_KEY_ID**：AccessKey ID
- **OSS_ACCESS_KEY_SECRET**：AccessKey Secret

#### 注意事项

1. **Bucket权限**：确保OSS Bucket已配置为公开读取（或至少允许写入）
2. **安全性**：AccessKey Secret是敏感信息，不要提交到代码仓库
3. **上传失败不影响主流程**：如果OSS上传失败，报告仍会正常生成
4. **上传内容**：
   - 报告文件（PDF优先，如果不存在则上传Markdown）
   - 表格附件（CSV格式，仅上传PDF中超过15行的表格）
5. **表格附件**：表格文件会自动上传到 `reports/YYYY_MM/tables/` 目录，并在飞书卡片中显示为"数据附件"链接

## 配置优先级

1. `.env` 文件（最高优先级）
2. 系统环境变量
3. 代码默认值（如果有）

## 常见问题

### Q: 为什么配置了环境变量但程序还是找不到？

A: 确保：
1. `.env` 文件在项目根目录
2. 已安装 `python-dotenv`：`pip install python-dotenv`
3. 重启终端/IDE

### Q: 如何在不同环境使用不同配置？

A: 可以创建多个 `.env` 文件：
- `.env.development`
- `.env.production`

然后在代码中根据环境加载对应的文件。

### Q: 配置信息会泄露吗？

A: `.env` 文件已在 `.gitignore` 中，不会被提交到代码仓库。但请确保：
1. 不要将 `.env` 文件提交到Git
2. 不要在代码中硬编码密钥
3. 定期轮换API密钥
