# 演示数据说明

本目录包含用于GitHub演示的脱敏数据。

## 文件说明

- `售前测试台账记录表_测试系统台账数据-2025_脱敏.xlsx`：2025年1-11月的台账数据（已脱敏）
- `新数据_脱敏.xlsx`：2025年10-12月的新数据（已脱敏）

## 数据说明

- 所有敏感信息已进行一致性脱敏处理
- 客户名称、产品名称等已替换为随机字符串
- 申请主键ID已替换为4位随机数字
- 样本量已进行一致性转换（原值/2 + 5000）
- 10-11月数据在两个文件中保持一致

## 使用方式

这些数据可用于：
- 项目演示和测试
- 功能验证
- 文档示例

**注意**：这些是脱敏后的演示数据，不包含真实业务信息。

## 数据一致性

两个文件中的10-11月数据已进行一致性处理，确保：
- 相同的客户简称在两个文件中对应相同的脱敏值
- 相同的产品名称在两个文件中对应相同的脱敏值
- 相同的申请主键ID在两个文件中对应相同的脱敏值
- 其他相关字段也保持一致性

## 脱敏规则

1. **申请主键ID**：替换为4位随机数字
2. **客户简称、客户类型、销售、部门名称**：一致性替换为字母数字组合
3. **产品名称**（售前主产品、系统主产品、子产品）：一致性替换为字母数字组合
4. **样本量**：一致性转换（原值/2 + 5000）
5. **其他自然语言字段**：替换为字母数字组合
6. **业务状态字段**（测试进度、接入意向、是否开通、是否调用）：保持不变
