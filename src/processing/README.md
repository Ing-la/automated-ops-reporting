# processing 模块说明

## generate_snapshot.py

生成snapshot数据的核心脚本。

### 核心逻辑

**snapshot是"截至当月的全量客户×产品×销售维度的最终业务状态定格"**，每个snapshot都是全量数据，不做时间裁剪。

### 功能

【月度运行任务】处理新月份数据，结合上月snapshot生成当月snapshot（可复现的月度流程）

### 使用方法

```bash
python src/processing/generate_snapshot.py <YYYY-MM> <raw_file_name>
```

示例：
```bash
# 处理2025年12月数据
python src/processing/generate_snapshot.py 2025-12 ops_data_2025_12.xlsx

# 处理2026年1月数据
python src/processing/generate_snapshot.py 2026-01 ops_data_2026_01.xlsx
```

### 输入文件

- `data/raw/ops_data_YYYY_MM.xlsx`：新月份的数据文件（包含近3个月的数据）

### 输出文件

- `data/snapshot/snapshot_YYYY_MM.csv`：当月的snapshot文件（CSV格式，中文列名）
- 如果同月份已存在，会自动添加字母后缀：`snapshot_YYYY_MM_a.csv`, `snapshot_YYYY_MM_b.csv` 等

### 输出字段（中文列名）

snapshot包含以下字段（共18个字段）：

**主键与核心维度**：
- 客户简称、子产品名称、快照月份

**日期字段**（对时间趋势分析至关重要）：
- 申请日期、测试返回日期

**组织与角色**：
- 销售人员

**客户与产品属性**：
- 客户类型、客户级别、售前主产品、系统主产品

**客户意向与流程状态**（二值化字段）：
- 申请测试、完成测试、可接入、不接入、不接入原因

**状态分类说明**：
- 申请测试：只要有申请日期就赋值1（基本上所有数据都要在这一列赋值1）
- 完成测试：只要有测试返回日期就赋值1（空值、-、NaN都算空值）
- 可接入：有接入意向或已接入
- 不接入：明确表示不接入

**状态判断规则**：
1. **申请测试**：只要有申请日期就赋值1
2. **完成测试**：只要有测试返回日期就赋值1（空值、-、NaN都算空值）
3. **接入意向**：基于接入意向字段判断（可以接入/无法接入）

**业务结果字段**：
- 已开通、已调用

**补充字段**：
- 样本量

### 处理逻辑

1. 读取新月份的raw数据（近3个月）
2. 转换为snapshot格式（中文列名，包含日期字段）
3. 加载上个月的snapshot（全量）
4. 合并逻辑：
   - 新数据中的记录（基于客户简称 + 子产品名称 + 申请日期）覆盖已有记录
   - 已有记录中不在新数据中的记录保留（历史遗留但仍有效的记录）
   - 新数据中的新记录添加
5. 生成当月的全量snapshot（包含所有历史数据截至当月的最终状态）

### 字段映射规则

- **状态字段**：接入意向优先级高于测试进度
- **二值化字段**：将"是/否"转换为1/0
- **日期字段**：转换为YYYY-MM-DD格式字符串
- **主键**：客户简称 + 子产品名称 + 申请日期（用于匹配记录）
  - 使用申请日期作为主键的一部分，支持同一客户+产品组合的多次测试记录
  - 如果申请日期为空，使用空字符串作为主键的一部分
  - **注意**：快照月份不是主键的一部分，它是snapshot的属性字段，在合并时会被统一设置为当前月份

### 数据排序

snapshot数据按以下规则排序（确保最新的数据在上面）：
1. **快照月份**（降序）：最新的月份在上面
2. **申请日期**（降序）：同一月份内，最新的申请在上面
3. **客户简称**（升序）：相同日期按客户名称排序
4. **子产品名称**（升序）：相同客户按产品名称排序

### 注意事项

1. **snapshot是全量的**：每个snapshot都包含截至当月的所有历史数据，不是只包含当月数据
2. **数据合并**：新数据会更新已有记录的状态，但不会删除历史记录
3. **数据排序**：合并后的数据按快照月份和申请日期降序排序，确保最新的数据在上面
4. **月度运行**：每月只需运行一次，处理当月的raw数据即可
5. **首次运行**：如果上个月的snapshot不存在，脚本会使用新数据作为全量snapshot（适用于首次初始化）
6. **日期字段**：申请日期和测试返回日期对时间趋势分析至关重要，已包含在snapshot中
