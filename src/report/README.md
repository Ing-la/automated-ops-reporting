# report 模块说明

## 功能概述

report模块负责将metrics计算结果转换为可读的Markdown格式报告。

## 模块结构

- `generate_report.py`: 报告生成主模块

## 使用方法

### 基本使用

```python
from src.report.generate_report import generate_monthly_report

# 生成2025年12月的报告
report_path = generate_monthly_report('2025-12')
```

### 报告结构

报告包含以下五个部分：

1. **总体运营盘点**
   - 规模与结构概览（本月新增）
   - 截至本月的整体进展（全量汇总）
   - 本月新增进展
   - 本月新开通和新调用详细列表

2. **流程与进度分析**（近3个月数据）
   - 测试流程进度分析
   - 测试周期与效率
   - 超长测试周期记录

3. **转化与收益分析**（核心，近3个月数据）
   - 收益转化核心指标
   - 产品维度收益分析
   - 客户维度收益分析
   - 有意向但未开通列表

4. **滞后与风险识别**（近3个月数据）
   - 测试完成但长期无意向
   - 明确有意向但未开通
   - 已开通但长期未调用（重点风险）

## 输出文件

报告保存在 `output/report/report_YYYY_MM.md`

## 注意事项

1. 报告生成依赖于metrics计算结果，需要先运行metrics计算
2. 报告格式为Markdown，可以在支持Markdown的编辑器中查看
3. 报告中的表格和列表会根据数据自动生成，如果数据为空则不显示
